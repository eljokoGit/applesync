# UI assets

Drop-in slot, read at start-up. Nothing here is required: if a file is
missing, the application falls back to the platform default.

| File       | Used for                                  | Format                                   |
|------------|-------------------------------------------|------------------------------------------|
| `icon.png` | window icon and taskbar icon              | PNG, square, 1024x1024, transparent background |

The icon is also expected to stay legible at 16x16, so it should be a single
shape with generous contrast, not a detailed illustration.
